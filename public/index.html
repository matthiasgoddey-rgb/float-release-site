A SIMPLE ROUTINE

Three small steps.
Then let the words flow.

Float keeps the process visible, so you stay in control from the first character to the last.

01

Choose a window

Pick a visible app window from the list. Float never chooses a destination for you.

02Aa· · ·

Prepare your text

Type or paste into Float, then choose a comfortable pace for the task at hand.

03↗

Start when ready

Use the countdown to click into the destination. Float can stop whenever you need it to.

MADE TO STAY OUT OF THE WAY

Just enough
helpful.

Float is a focused desktop utility: a few useful controls, clear feedback, and no background clipboard watching.

Read the full user guide ↗

Text stays yours

Your text and recent items stay in memory for the current session, then clear when Float closes.

01

Clipboard only by choice

Float does not monitor the clipboard. Add clipboard text to History only when you choose Add clipboard.

02

Designed around focus

Float stops if the destination closes or focus moves to another app. You can stop it from Float too.

03

YOUR SESSION, YOURS

Quiet by design.

Float keeps text in memory while it is open. It does not monitor the clipboard, and it clears session text when you close the app.
