A small, considered tool

Nothing watching.

Read the user guide ↗
Text lives in memory
Your text and recent items stay in the current session, then clear when the app closes.
01
Clipboard, only by choice
Floater Typist does not monitor the clipboard. Text enters History only when you choose Add clipboard.
02
Focus stays yours
Typing stops if the destination closes or focus moves to another app. You can also press Stop.
03

Your session, yours

Quiet by design.

Text stays in memory while Floater Typist is open. The app does not monitor the clipboard, and it clears session text when you close it.

  • No clipboard monitoring
  • History clears on close
  • No administrator access
